# Advisor คือโฟลเดอร์ของไฟล์ markdown ไม่ใช้ vector DB

Advisor หนึ่งตัวคือโฟลเดอร์ธรรมดาที่มี `CLAUDE.md` และ Channel Knowledge เก็บเป็นไฟล์ markdown ทั้งหมด เมื่อตอบคำถาม Claude ค้นจาก Topic Map และ index แล้วใช้ grep กับ Video Record ทั้งระบบไม่มี vector DB, embeddings หรือ server ที่ต้องรันค้างไว้ เลือกแบบนี้เพราะเป็นเครื่องมือใช้คนเดียว และช่องมีวิดีโอระดับหลักพันคลิป ซึ่งยังค้นแบบนี้ได้ทัน ได้ไฟล์ที่คนอ่านเองได้ ย้ายโฟลเดอร์ไปไหนก็ได้ และแค่เปิด Claude ในโฟลเดอร์ก็ใช้งานได้ทันที

## Considered Options

- **RAG + vector DB:** ค้นด้วยความหมายได้ดีกว่า แต่ต้องดูแล index และ embeddings ไม่สามารถเปิดไฟล์อ่านเองได้ และยังไม่จำเป็นที่ขนาดข้อมูลระดับนี้
- **NotebookLM:** ได้คำตอบที่มีอ้างอิงแหล่งที่มา แต่จำกัดจำนวนแหล่งต่อ notebook ควบคุมกฎการตอบเองไม่ได้ เช่น Recency Weighting และ Provenance Label และข้อมูลไม่ได้อยู่ในเครื่อง

## Consequences

แต่ละ Advisor ใช้งานได้ด้วยตัวเองโดยไม่ต้องพึ่งโฟลเดอร์อื่น ถ้า Channel เดียวกันอยู่ในหลาย Advisor แต่ละ Advisor จะ Ingest แยกกันเองโดยไม่แชร์ข้อมูล ยอมรับว่าต้อง Ingest ซ้ำ เพื่อแลกกับการที่ย้ายหรือลบโฟลเดอร์ไหนก็ได้โดยไม่กระทบโฟลเดอร์อื่น

ถ้าวันหนึ่ง Advisor มีหลายหมื่น Video Record จนค้นด้วย grep ไม่ทัน ให้เพิ่ม index แบบ full-text (เช่น SQLite FTS) โดยยังเก็บ markdown เป็นข้อมูลหลักไว้เหมือนเดิม

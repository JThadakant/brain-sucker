# แยกที่เก็บ: Channel Knowledge อยู่ใน Advisor ส่วนไฟล์หนักอยู่ใน cache นอก OneDrive

Channel Knowledge (markdown ขนาดเล็ก) เก็บไว้ในโฟลเดอร์ Advisor ซึ่งอาจอยู่ใน OneDrive และ sync ได้ ส่วนวิดีโอ ไฟล์เสียง และเฟรมภาพ เก็บที่ `C:\brain-sucker-cache\` (ตั้งค่าได้) และลบทิ้งหลังประมวลผลแต่ละ Video เสร็จ เหตุผลคือถ้าให้ OneDrive sync ไฟล์วิดีโอชั่วคราวหลาย GB จะทำให้ช้าและเปลืองพื้นที่ cloud แต่ความรู้ต้องอยู่คู่กับ Advisor เพื่อให้ย้ายโฟลเดอร์ได้ทั้งก้อน
